{# The auto-renewal fields: a mode, the one value that mode takes, and a cap. Shared by the tariff form and the forms that create and edit a client: a renewal is one more thing a tariff hands a client, and the client then keeps. Expects: renew (a dict with mode, value and max; may be empty) and rid, a prefix that keeps the ids apart where two forms share a page. Every part is drawn and none is hidden here. The script in base_admin.html hides the ones the chosen mode does not use, so a page without JavaScript shows them all — and still posts the right thing, because the server takes the value from the field the mode names (renewal.from_form) and ignores the rest. One field per mode, rather than one field whose meaning changes, is what makes that so. renew_present says that these fields were on the form at all. The mode cannot say it for itself: "off" is an empty value, and FastAPI reads an empty form field as one that was never sent — so, without the marker, switching a renewal off looked exactly like a form that had no such fields, which is the one drawn for a panel that knows no renewal and must change nothing. The period and the cap carry no upper bound of the browser's. The server has one for a value being set; a client whose renewal was set in 3x-ui itself may be past it, the form opens on that value, and a browser that refused it would refuse to save anything else about that client. #} {% import "_fields.html" as fields %} {% set r = renew or {} %} {% set mode = r.mode or "" %}
